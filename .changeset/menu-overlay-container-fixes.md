Fixed: an overlay opened in a container of the caller's (`Overlay`'s `portalContainer`) or of an app's React Aria `UNSAFE_PortalProvider` carries only the theme attributes that differ from what the container inherits, as in the element in full screen, so an app's own `:root` token values reach a menu or dialog there; it wrote every attribute, which declared the theme's values again. In a menu, Home, End, Page Up and Page Down only move focus: their default no longer scrolls an element around the menu. In a bottom sheet, a menu's first page fades in again as it shows after Back, as its other pages do. In a menu's bottom sheet, an action or a choice on a submenu's page keeps focus on the page as the sheet closes, instead of dropping it to the page's `<body>` until the sheet has gone; Escape and Left (Right in right to left) on the back button go back one page instead of closing the sheet; a submenu's own `className` and `style` reach its page; and a sheet whose code fails to load closes, rather than leaving its trigger open over nothing, and tries again on the next open.
